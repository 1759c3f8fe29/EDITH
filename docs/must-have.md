# The must-have list — verbatim source

Kept unedited so the decomposition in `TASKS.md` (Phase N, plus the coverage table
above it) can always be checked against what was actually asked for. Nothing here
is a task; every line is a promise to a user, and Phase N is where each one is
turned into work that can be finished and verified.

---

must have

Multi-step missions
One instruction becomes a plan: scan → classify → create folders → move files → report. You watch it happen.

File system mastery
Bulk organize downloads, find duplicates, rename by pattern, archive old projects — in seconds, not Saturdays.

Browser automation
Open sites, search, navigate, and manage tabs autonomously. The browser becomes a tool the AI uses for you.

Screen awareness
The AI can read what's on your screen and act on it — context other assistants simply don't have.

Human-in-the-loop safety
Critical actions ask first. Every action is logged. Autonomy with a leash you hold.

System guardian
Monitors performance, flags resource hogs, and optimizes your PC on request.

Natural speech, not syntax
No memorized phrases. Say it like you'd say it to a person sitting at your PC — works out the steps.

App control
"Open Premiere", "close all Chrome windows", "switch to Spotify" — application control without touching the keyboard.

File operations by voice
Create, find, move, rename, and organize files and folders across your drives with a sentence.

Voice-driven browsing
Open sites, run searches, manage tabs. Your browser becomes hands-free.

System commands
Check battery, RAM, and storage; optimize performance; control volume and settings by asking.

Hands-free messaging
Dictate and send WhatsApp messages while you keep working — or gaming.
